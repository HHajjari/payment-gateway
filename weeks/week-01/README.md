# Week 1 — Payment Domain & Spring Boot Foundation

## Status

**IN PROGRESS**

## Goal

Understand the payment-gateway domain and establish a clean Spring Boot foundation without prematurely introducing PostgreSQL, Kafka, Redis, microservices, or other infrastructure.

## This Week

- Understand Merchant, Payment, Money, Payment Method, authorization, capture, cancellation, and refund concepts.
- Define the first version of the domain model.
- Bootstrap the payment-gateway Spring Boot application.
- Implement only the Week 1 API/domain behavior defined in `assignment.md`.
- Write meaningful domain and API tests.
- Document architectural decisions and questions.
